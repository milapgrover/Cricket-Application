🏏 Cricket Live Score Application

A full-stack **Cricket Live Score Application** that provides real-time cricket information including tournaments, teams, players, rankings, and match details.  
The project is built using **Spring Boot** for the backend and **React (Vite)** for the frontend.

---

## 🚀 Features

- 📊 Live cricket tournaments and series information  
- 🏏 Team and player management  
- 📅 Match schedules and match details  
- 🏆 Team rankings (Test, ODI, T20)  
- 🔐 Secure REST APIs  
- 🌐 Responsive and modern UI  
- 🗄️ MySQL database integration  

---
